# Dữ liệu

Dữ liệu **không có trên GitHub** (BTC Datathon 2026 không cho chia sẻ). Mỗi thành viên tự join competition Datathon 2026 trên Kaggle,
tải 14 file CSV và giải nén vào `data/raw/datathon-2026-round-1/` (ví dụ `data/raw/datathon-2026-round-1/sales.csv`).
Nếu để dữ liệu ở chỗ khác, đặt biến môi trường `DS317_DATA_DIR` trỏ tới thư mục chứa 14 file CSV.
